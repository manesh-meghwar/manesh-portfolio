MANESH KUMAR STATIC PORTFOLIO

TECHNOLOGY
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript

NO React, Next.js, Node.js, npm, database, or build step is required.

START THE WEBSITE
1. Extract the ZIP.
2. Open index.html in your browser.

For the best local test, you may also use the VS Code "Live Server" extension,
but it is optional.

UPLOAD TO GITHUB PAGES
1. Create a public GitHub repository.
2. Upload every file and folder from this package to the repository root.
3. Open Repository Settings > Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Select the main branch and the /root folder.
6. Save and wait for GitHub to provide your portfolio URL.

EDIT CONTENT
- Home/About: index.html
- Resume: resume.html
- Project content: js/main.js
- Blog: blog.html
- Certificate content: js/main.js
- Contact links: contact.html
- Colors and design: css/style.css
- Navigation and footer: js/main.js

ADD YOUR PHOTO
1. Create an assets folder.
2. Put your photo there, for example: assets/manesh-kumar.jpg
3. In index.html, replace the portrait-placeholder div with:
   <img src="assets/manesh-kumar.jpg" alt="Manesh Kumar" class="img-fluid">

The Bootstrap CSS, JavaScript, and icons load from public CDN links, so an
internet connection is required for Bootstrap styling and components.

ADD YOUR INTRODUCTION VIDEO
1. Create the assets folder if it does not exist.
2. Export your video as an MP4 file.
3. Name it exactly: introduction-video.mp4
4. Place it here: assets/introduction-video.mp4
5. Open resume.html. The video will appear automatically.

Recommended video:
- Length: 60 to 90 seconds
- Orientation: horizontal 16:9
- Resolution: 1920x1080 or 1280x720
- File size: preferably below 25 MB
- Speak about your background, master’s research, AI/ML interests, strongest
  skills, and the position you are seeking.
